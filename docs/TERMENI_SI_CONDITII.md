## 1. Descrierea Serviciului

1.1. **Verifact** este un instrument open-source bazat pe inteligență artificială, conceput pentru verificarea veridicității afirmațiilor, știrilor și conținutului din spațiul digital și rețelele sociale.
1.2. Serviciul permite utilizatorilor să introducă text, URL-uri sau screenshot-uri pentru a genera rapoarte de analiză automatizată prin agregare din baze de date de fact-checking, surse de presă, surse guvernamentale/oficiale și rețele sociale.
1.3. Serviciul este oferit pe trei niveluri de acces (Tier-uri):
* **Free**: Acces gratuit cu număr limitat de verificări lunare și rapoarte standard.
* **Pro**: Abonament plătit oferind un volum extins de verificări, export PDF și cheie API personală.
* **Business / Enterprise**: Abonament comercial pentru volume mari, acces integrat API, webhook-uri și suport tehnic.
